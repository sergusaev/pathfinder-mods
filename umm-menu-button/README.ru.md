# Unity Mod Manager in Game Menus (Pathfinder: Kingmaker и Wrath of the Righteous)

[English version](README.md)

Мод Unity Mod Manager для обеих игр Pathfinder. Он добавляет пункт «Unity Mod Manager» в главное меню и Esc-меню игры. Менеджер модов открывается из меню при любом управлении: клавиатура и мышь, геймпад Xbox или PlayStation, Steam Deck.

## Что делает

- **Пункт в четырёх меню каждой игры:** главное меню и Esc-меню, в интерфейсе для мыши и в интерфейсе для геймпада (консольном). Пункт стоит прямо перед «Выйти» и открывает окно Unity Mod Manager.
- **Вид как у игры.** Пункт — копия соседнего: тот же шрифт, цвета и рамки. В главных меню и в Esc-меню для геймпада у него большая первая буква, как у пунктов игры, а в меню Kingmaker для геймпада ещё и разделитель. Стик и кнопки геймпада проходят через него по порядку, как через пункты игры.
- **Меню не разрастаются.** Списки главных меню уменьшаются на долю добавленного пункта и занимают прежнее место. В главном меню Kingmaker для мыши рамки вокруг первых букв нарисованы в картинке стола, и мод дорисовывает там восьмую рамку для нового пункта. В главном меню Kingmaker для геймпада рамка выделения удлиняется на ровных участках, чтобы вместить более длинную надпись.
- **Один пункт, кто бы ещё его ни добавлял.** Bag of Tricks добавляет свою кнопку Unity Mod Manager в Esc-меню Kingmaker для мыши; этот мод встаёт на её место, так что в каждом меню пункт один.
- **Без окна при запуске.** При загрузке мод выключает настройку Unity Mod Manager «показывать окно при запуске»: менеджер теперь открывается из меню.
- **Всегда включён.** Мод — это вход в менеджер модов, поэтому, если снять с него галочку в списке модов, он включается обратно.

## Установка

1. В игре должен стоять Unity Mod Manager: [Steam Deck](../docs/steam-deck.ru.md), [Windows](../docs/windows.ru.md). Как распаковать, обновить и удалить мод, с командами — [установка модов вручную](../docs/mods.ru.md).
2. Скачайте zip для своей игры из [Releases](https://github.com/sergusaev/pathfinder-mods/releases): `UmmMenuButton-<версия>-kingmaker.zip` или `UmmMenuButton-<версия>-wotr.zip`. Библиотеки двух игр не взаимозаменяемы.
3. Распакуйте в папку модов так, чтобы получилось `Mods/UmmMenuButton/Info.json`.
4. Запустите игру; в главном меню появится пункт «Unity Mod Manager».

## Сборка

`./build.sh` собирает обе игры, `./build.sh --game kingmaker --install` собирает и ставит одну; см. [README репозитория](../README.ru.md).
