# Свитки (Pathfinder: Kingmaker и Wrath of the Righteous)

[English version](README.md)

Мод для Unity Mod Manager для обеих игр и обоих интерфейсов (геймпад, клавиатура и мышь). Учит волшебников, магусов и других заклинателей, переписывающих заклинания, сразу всем свиткам из инвентаря группы — так же, как это делает сама игра: свиток тратится, заклинание попадает в книгу.

## Что делает

- **Вся группа.** Каждый свиток достаётся тому, кто может его выучить. Если копий меньше, чем желающих, кому достанется — решают правила вкладки «Настройки». Рецепты из инвентаря изучает вся группа.
- **Один персонаж.** Выберите персонажа на вкладке «Персонажи»: он выучит всё, что может, в том числе то, что по плану группы досталось бы другому; такие заклинания помечены в списке.
- **Сначала подтверждение.** Сначала открывается окно самой игры со списком: персонажи, под каждым — его заклинания с уровнем и школой. Без подтверждения ничего не изучается. Школа зелёная с поднятым пальцем, если это школа специализации персонажа, красная с опущенным — если запретная.
- **Счётчики.** Рядом с каждым персонажем — сколько свитков ему даёт план группы; числа персонажей в сумме дают число «Вся группа».
- **Не изучается:** заклинание, которое уже есть в книге; заклинание не из списка класса; заклинание, для которого мала характеристика заклинателя (нужно 10 + уровень заклинания). По желанию (по умолчанию выключено) — заклинания запретных школ.
- **Как открыть окно.** С геймпадом — карточка «Свитки» в меню игры. С клавиатурой и мышью — кнопки над кнопками меню игры: свиток изучает всё для всей группы, свиток с шестерёнкой открывает окно. На вкладке «Справка» в окне — всё управление.

Картинки сделаны один раз из свитка карточки «Журнал» самих игр и зашиты в DLL.

## Установка

1. В игре должен стоять Unity Mod Manager: [Steam Deck](../docs/steam-deck.ru.md), [Windows](../docs/windows.ru.md). Как распаковать, обновить и удалить мод, с командами: [установка модов вручную](../docs/mods.ru.md).
2. Скачайте zip для своей игры со страницы [Releases](https://github.com/sergusaev/pathfinder-mods/releases): `LearnScrolls-<версия>-kingmaker.zip` или `LearnScrolls-<версия>-wotr.zip`. DLL двух игр не взаимозаменяемы.
3. Распакуйте его в папку модов, чтобы получилось `Mods/LearnScrolls/Info.json`.
4. Запустите игру; в окне UMM появится «Scrolls» с зелёным статусом.

## Сборка

`./build.sh` собирает обе игры, `./build.sh --game kingmaker --install` собирает и ставит одну; подробнее — в [README репозитория](../README.ru.md#сборка-из-исходников). Код для каждой игры — в `src/kingmaker` и `src/wotr`. Картинки в `art/` делает `art/make_art.py` (Pillow) из исходников, один раз вырезанных из спрайтов игр.
